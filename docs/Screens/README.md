# Telas — PEÇA

Referências visuais das telas, exportadas do Claude Design como HTML.

- Gere o prompt com `/peca.screen` e salve a exportação aqui como `<ator>-<tela>.html`, em inglês e
  kebab-case, por exemplo `visitor-home.html`. Variações usam sufixo, como `-empty` ou `-v2`.
- Antes de implementar uma tela, confira se existe um arquivo aqui e siga-o fielmente. O
  comportamento continua definido em `/specs`; se os dois divergirem, corrija a spec primeiro.
- A identidade visual está em `../peca-front-end/docs/` e os tokens em
  `../peca-front-end/app/globals.css`.
- Use só dados sintéticos nos prompts e nas telas exportadas.
